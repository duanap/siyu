# TASK-027：首页与“我的”APP 化重构

## 状态

已合并、CI 通过并正式关闭

## 模型与推理

- 推荐模型：Sol
- 推理：High
- 是否使用子代理：否

## 目标

- 按负责人选定的“方案 1 / 月度叙事”重构个人与情侣首页，保持月度结余为唯一视觉主角。
- 首页使用真实周期实例和本人借贷事实形成紧凑待办，并保留最近账目与个人/情侣隐私边界。
- 将 `/account` 重构为资料、共同生活、财务计划、数据与安全、外观设置的分组入口。
- 首页、明细、记账、统计和“我的”使用一致图标与连续底部导航，兼容底部安全区。
- 实现金额隐藏偏好与日间、夜间、跟随系统三档主题，并在本机持久化。

## 非目标

- 不修改统计、账目、周期、借贷、通知、工资、攒钱 API 或数据库契约。
- 不新增通知类型、预算、账户余额、头像上传、资料编辑、Push 或原生容器代码。
- 不把个人借贷、工资或其他本人私有数据展示到情侣账本。
- 不新增生产依赖，不重构与首页和“我的”无关的业务页面。

## 禁止修改

- API、Worker、Prisma Schema、迁移、权限、部署配置和生产凭据
- 既有财务聚合、金额整数分、账本成员、通知接收人和来源账目规则
- 当前工作区尚未提交的部署运行手册内容

## 当前状态与依赖

- TASK-009 首页已能读取真实月度汇总、成员支出和最近账目，但控件占据首屏、存在过期模块提示。
- `/account` 仍是平铺入口页，缺少底部导航、分组信息架构、主题和金额隐私设置。
- TASK-011、014、021 已提供本人借贷、待确认周期实例和本人通知接口，可用于只读待办与角标。
- 仓库已有 Ant Design Vue 及其运行时图标资产；本任务不得增加新的生产依赖。

## 风险

- 首页辅助接口可能失败或数据量较大，必须与核心统计失败隔离且不得伪造待办。
- 情侣首页不得读取本人借贷；成员支出必须保持中性表达，避免形成消费排名。
- 跟随系统主题需要响应系统变化，同时不覆盖用户显式选择。
- 320px 下顶部控件、长昵称和金额可能拥挤；所有点击区仍需不少于 44px。
